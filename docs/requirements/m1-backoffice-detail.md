## 0. 领域概念（先统一叫法）

| 概念 | 含义 | 说明 |
|---|---|---|
| **生豆品种档案** | 某种生豆的「品名」 | 例：埃塞俄比亚·耶加雪菲 G1·水洗。可反复采购 |
| **生豆批次（采购批）** | 一次到货的一批生豆 | 对应一条采购记录，有独立批次号，按公斤计库存 |
| **熟豆商品** | 对外可卖的熟豆产品 | 例：耶加雪菲 G1 水洗·中浅烘。一个熟豆商品可由多次烘焙补货 |
| **烘焙批次** | 一次烘焙 | 既是「生产记录」，也是熟豆的**库存批次**（带烘焙日期，决定新鲜度） |
| **库存流水** | 一切库存变动的记账 | 入库/出库/盘点都产生流水，不可删除只可冲销 |

**库存计量：全部按公斤（kg）。** 包装规格（250g/500g/1kg 袋）是 M2 销售属性，M1 不参与换算。

**出库扣减策略：自动先进先出（FIFO）**，即优先扣最早烘焙的批次；出库时可改为手动指定批次。

## 1. 系统用户管理

**页面与操作**
| 页面 | 操作 |
|---|---|
| 登录页 | 账号+密码登录、记住我、忘记密码（管理员重置） |
| 用户列表 | 搜索/筛选（角色、状态）、新增用户、查看 |
| 新增/编辑用户 | 保存、取消 |
| 用户详情/行操作 | 启用、停用、重置密码、改角色 |

**字段**
| 字段 | 说明 | 必填 |
|---|---|---|
| 用户名 | 登录名，唯一 | ✅ |
| 姓名 | 显示名（如「阿莫」） | ✅ |
| 密码 | 初始由管理员设置，登录后可改 | ✅ |
| 角色 | 管理员 / 员工 / 只读 | ✅ |
| 状态 | 启用 / 停用 | ✅ |
| 最近登录 | 系统记录 | — |

**规则**
- 密码加密存储；不可明文查看。
- 连续 5 次密码错误锁 15 分钟。
- 停用用户立即无法登录；已登录会话下次请求失效。
- 不能删除自己、不能停用最后一个管理员。

## 3. 咖啡生豆管理

**生豆品种档案**
| 字段 | 说明 | 必填 |
|---|---|---|
| 名称 | 例：耶加雪菲 G1 水洗 | ✅ |
| 产地 | 国家/产区 | 建议 |
| 处理法 | 水洗 / 日晒 / 蜜处理… | 建议 |
| 豆种 | 如 Heirloom / Typica | 选填 |
| 默认供货商 | 快速带入采购单 | 选填 |
| 备注 | 杯测/风味描述 | 选填 |

**采购入库（生豆批次 + 入库）**
| 字段 | 说明 | 必填 |
|---|---|---|
| 供货商 | 从供货商档案选 | ✅ |
| 品种 | 从生豆品种档案选（可先建档案） | ✅ |
| 采购日期 | 到货日 | ✅ |
| 批次号 | 自动生成（可改），如 `GB-2026-0001` | ✅ |
| 数量 | 公斤，支持小数 | ✅ |
| 采购单价 | 元/kg | ✅ |
| 金额 | = 数量 × 单价，自动算（可改） | ✅ |
| 备注 | 含水率、到货质量等 | 选填 |

**页面与操作**
| 页面 | 操作 |
|---|---|
| 品种列表 / 详情 | 增改、查看采购历史 |
| 采购入库单 | 选择供货商与品种、填批次与数量、保存即入库 |
| 生豆库存 | 按批次看剩余 kg；查看流水；报废出库（填数量+原因） |

**规则**
- 采购单保存 → 自动生成该生豆批次的**入库流水**，库存增加。
- 报废出库不可超当前批次剩余量。
- 采购价用于日后成本核算，M1 不计算毛利。

## 4. 烘焙管理

**新建烘焙批次（登记中）**
| 字段 | 说明 | 必填 |
|---|---|---|
| 烘焙批次号 | 自动，如 `RB-2026-0001` | ✅ |
| 烘焙日期 | 默认今天 | ✅ |
| 烘焙师 | 选当前用户或员工 | ✅ |
| 设备 | 烘焙机位（可选） | 选填 |
| 熟豆商品 | 本次烘焙产出的商品（可现场新建） | ✅ |
| 烘焙度 | 浅 / 中浅 / 中 / 中深 / 深 | ✅ |
| **生豆用料明细** | 多行：选生豆批次 → 显示剩余量 → 填用量 kg | ✅ |
| 投入合计 | 自动求和 | — |
| 曲线记录 | 一爆时间、出炉温度℃、总时长、关键节点备注 | 选填 |

**出炉登记（完成）**
| 字段 | 说明 | 必填 |
|---|---|---|
| 出炉量 | 产出熟豆 kg（实测） | ✅ |
| 失重率 | = (投入−出炉)/投入，自动算，供参考 | — |
| 质检结果 | 合格（进入可售）/ 不合格（报废） | ✅ |

**页面与操作**
| 页面 | 操作 |
|---|---|
| 烘焙批次列表 | 筛选（日期/状态）、查看详情、编辑草稿、作废 |
| 新建批次 | 录入生豆用料与熟豆商品 → 存为草稿 |
| 批次详情 | 出炉登记、查看用料/产出追溯、质检确认、作废（管理员） |

**状态流转**
```
草稿（登记中）→ [出炉登记] → 待质检 → [合格] → 可售（已入库）
                              ↘ [不合格] → 熟豆按废料出库
任意状态（未出库）→ [作废]（管理员，需留痕）
```

**关键联动（最重要的一条）**
- 出炉登记「合格」的瞬间，系统**一次完成**：
  1. 扣减所选生豆批次库存（按用料明细逐行扣，扣不动则报错阻止）；
  2. 生成熟豆商品下**烘焙批次=库存批次**的入库，剩余量 = 出炉量；
  3. 生成对应库存流水。
- 作废一个已入库的烘焙批次 = 反向冲销上述库存，需管理员确认并记录原因。

## 5. 熟豆库存与进出库

**熟豆商品**
| 字段 | 说明 | 必填 |
|---|---|---|
| 名称 | 例：耶加雪菲 G1 中浅烘 | ✅ |
| 关联生豆品种 | 便于追溯 | 建议 |
| 默认烘焙度 | 展示用 | 选填 |
| 库存预警阈值 | kg，低于时提醒补烘 | 建议 |
| 状态 | 在售 / 停售 | ✅ |
| 售价 | M2 启用，M1 可先填 | 选填 |

**出库单**
| 字段 | 说明 | 必填 |
|---|---|---|
| 熟豆商品 | — | ✅ |
| 出库类型 | 销售 / 样品 / 损耗 / 盘点调整 | ✅ |
| 客户 | 类型为「销售」时必填，从客户档案选 | 条件必填 |
| 数量 | kg | ✅ |
| 扣减明细 | 自动 FIFO 分配批次与数量，**可手动改** | — |
| 备注/去向 | 订单号、用途等 | 选填 |

**入库单（手动/盘点）**
| 字段 | 说明 | 必填 |
|---|---|---|
| 熟豆商品 | — | ✅ |
| 类型 | 盘盈入库 / 调整 | ✅ |
| 数量 | kg | ✅ |
| 备注 | 原因 | 建议 |

**页面与操作**
| 页面 | 操作 |
|---|---|
| 库存看板 | 每个熟豆商品：总库存、按批次列表（烘焙日期/剩余/已存放天数）、预警标红 |
| 商品管理 | 增改熟豆商品、设阈值 |
| 出库/入库单 | 新建、保存即记账 |
| 库存流水 | 按商品/批次/类型/时间筛选查看 |

**规则**
- 出库校验：任一被扣批次不够即阻止（或提示拆分），不允许负库存。
- FIFO 明细保存前可调整手动选批次（批次剩余量即时可见）。
- 流水只增不改；录错用「冲销/红冲」处理（管理员）。
- 预警：某商品总库存 < 阈值 → 看板标红，并进入「待补烘」提醒列表。

## 7. 操作日志与审计

**记录范围**：登录、用户增删改/重置密码、采购入库、烘焙批次登记/出炉/作废、出入库、盘点调整、冲销。

**字段**
| 字段 | 说明 |
|---|---|
| 操作人 | 用户 |
| 时间 | 精确到秒 |
| 动作 | 如「烘焙出炉登记」 |
| 对象 | 关联单号（批次号/单号） |
| 详情 | 关键字段前后值（如数量、状态） |

**规则**
- 普通员工看不到他人日志修改类记录？——管理员可查全部；员工仅能看自己的操作（可配置）。
- 日志只增不删（M1 不做日志清理）。
